### 🌱 Project Description
This project aims to **predict potential machine failures** in agricultural environments using **AI and IoT sensor data**.  
The dashboard provides real-time monitoring and prediction insights that help farmers and engineers perform **predictive maintenance**, preventing costly equipment downtime.

#### 🎯 Core Objectives
- Analyze sensor data (temperature, torque, speed, tool wear, etc.)
- Predict if a machine is likely to fail soon
- Visualize machine health through an interactive Streamlit dashboard
- Enable cloud-based access and scalability using AWS

---

### 🧠 Key Features
✅ Machine Learning model for failure prediction  
✅ Real-time simulation of incoming IoT data  
✅ Interactive Streamlit dashboard with Plotly charts  
✅ Separate modules for preprocessing, model training, and visualization  
✅ Cloud-ready structure for AWS deployment
