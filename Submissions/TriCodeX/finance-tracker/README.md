# 💰 Gamified Personal Finance Tracker

A full-stack web application that makes personal finance management engaging through gamification elements like achievements, leaderboards, and progress tracking.

## 🎯 Features

### 💳 Financial Management
- **Transaction Tracking**: Add, categorize, and search income/expenses
- **Budget Management**: Set monthly budgets with visual progress indicators
- **Savings Goals**: Create and track progress towards financial goals
- **Data Visualization**: Interactive charts for spending analysis

### 🏆 Gamification
- **Achievement System**: Unlock badges for financial milestones
- **Points & Levels**: Earn points for positive financial behaviors
- **Leaderboard**: Compete with other users globally
- **Daily Streaks**: Maintain consistency with streak tracking
- **Reward System**: Unlock features and bonuses as you level up

### 📊 Analytics & Reports
- **Dashboard Overview**: Financial health at a glance
- **Spending Analysis**: Category-wise expense breakdown
- **Progress Tracking**: Visual goal and budget progress
- **Data Export**: Export financial data to CSV/PDF

## 🛠️ Tech Stack

**Frontend:**
- React with Vite
- Tailwind CSS for styling
- Chart.js for data visualization
- React Router for navigation

**Backend:**
- Node.js with Express
- Mock API with in-memory data
- JWT authentication (mock)
