# 🎓 SkillBridge - Online Learning Management System

A full-stack web platform for managing short courses where instructors can upload content and students can enroll, complete lessons, and track their learning progress.

## 🚀 Features

### 👨‍🎓 Student Features

- Browse and enroll in courses
- Track progress with visual progress bars
- Earn completion certificates
- Rate and review courses

### 👨‍🏫 Instructor Features

- Create and manage courses
- Upload course content
- Track student enrollment and progress
- Course analytics

### 👨‍💼 Admin Features

- Platform analytics dashboard
- User management and approval
- Course management
- Performance metrics

## 🛠️ Tech Stack

**Frontend:**

- React with Vite
- Tailwind CSS for styling
- React Router for navigation
- Axios for API calls

**Backend:**

- Node.js with Express
- Mock API with in-memory data
- RESTful API design

## 🏃‍♂️ Quick Start

### Prerequisites

- Node.js 16+
- npm or yarn

### Installation

1. **Frontend Setup:**

```bash
cd frontend
npm install
npm run dev
```
